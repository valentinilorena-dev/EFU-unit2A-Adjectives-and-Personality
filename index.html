Adjectives as nouns

the + adjective can refer to a social group: the young, the elderly, the sick, the unemployed. Use a plural verb: The elderly are...

Nationalities

Some nationality adjectives follow the same pattern: the French, the British, the Dutch, the Swiss. To refer to one person, say a French woman, for example.

Adjective order

Typical order: opinion → size → age → shape → colour → pattern → origin → material → noun.

Useful phrases

be ready to = be prepared; treat = behave towards; be through = experience; break down = lose emotional control; deal with = handle.
